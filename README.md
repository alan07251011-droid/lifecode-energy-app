# 🌿 老臣聊心室｜生命密碼與綠植能量調頻

> 「八字與數字只是指引天賦與盲點的『地圖』，而非限制生命的『框架』。真正的智慧在於調和能量與修煉心性。」

本專案由 **綠藝國際學苑 ╳ 老臣聊心室** 打造，結合國際園藝治療師專業與生命密碼三元九運核心算法，提供大眾快速探索先天命宮守護星、天性本質、思維盲點、專屬五行綠植調頻處方與靜心書寫陪伴。

---

## 🌟 核心功能特色

1. **三元九運先天命宮計算**：依據西元出生年與性別（乾命/坤命）精準換算個人命宮守護星（貪狼、巨門、祿存、文曲、武曲、破軍、左輔、右弼）。
2. **天賦與思維盲點深度解析**：清晰呈現天性優勢與潛在盲點，引導溫柔自我覺察。
3. **專屬五行綠植能量處方**：精選搭配五行對應植栽（如虎尾蘭、圓葉椒草、白網紋、彩虹千年木等）與居家/辦公室伏位安定吉利方位。
4. **觀音心法靜心書寫提問**：量身打造深層冥想書寫題目，引導釋放內耗與壓力。
5. **心靈陪伴與深度諮詢漏斗**：
   - 【靈魂初見】生命密碼核心特質簡析（體驗版）
   - 【人生導航】你的專屬生命使用手冊（完整版）
   - 【30天找回自己】深度陪跑諮詢計畫審查

## 🚀 安裝與執行方式

### 1. 安裝依賴套件
```bash
pip install -r requirements.txt
```

### 2. 啟動 Streamlit 應用程式
```bash
streamlit run app.py
```

瀏覽器將會自動開啟 `http://localhost:8501`。
